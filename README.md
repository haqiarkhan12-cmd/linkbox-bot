# 📦 LinkBox Bot

LinkBox is a Telegram bot for processing permitted public file links.

## ✨ Features

- 📥 File download
- 🔗 URL processing
- 📁 Download history
- 👤 User database
- 💎 Premium system
- 👑 Admin panel
- 🚫 Ban / Unban
- 📊 Statistics
- 🧹 Automatic temporary-file cleanup
- 🛡️ Basic URL security

## 🛠️ Technology

- Python
- python-telegram-bot
- SQLite
- aiohttp
- aiosqlite
